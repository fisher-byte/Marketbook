# 配置管理系统使用指南

## 概览

MarketBook 采用统一的配置管理系统，支持：
- ✅ 环境变量管理
- ✅ 配置验证
- ✅ 默认值设置
- ✅ 多环境差异化配置

## 快速开始

### 1. 创建环境配置文件

```bash
# 复制环境变量模板
cp .env.example .env

# 根据需要修改配置
vi .env
```

### 2. 使用配置

```javascript
const config = require('./config');

// 获取配置值
const port = config.server.port;              // 3000
const jwtSecret = config.jwt.secret;          // 从环境变量读取

// 使用点号路径获取配置
const logLevel = config.get('logging.level'); // 'debug'

// 环境判断
if (config.isProduction()) {
  // 生产环境逻辑
}
```

## 配置分类

### 服务器配置 (`config.server`)

```javascript
{
  port: 3000,              // 服务器端口
  host: '0.0.0.0',         // 监听地址
  env: 'development',      // 环境名称
  isDevelopment: true,     // 是否开发环境
  isProduction: false,     // 是否生产环境
  isTest: false,           // 是否测试环境
}
```

### 数据库配置 (`config.database`)

```javascript
{
  mongodb: {
    uri: 'mongodb://localhost:27017/marketbook',
    options: { ... }
  },
  useMemoryStore: true,    // 当前使用内存存储
}
```

### JWT 认证配置 (`config.jwt`)

```javascript
{
  secret: 'your-secret-key',        // JWT密钥（生产环境必须修改）
  accessTokenExpiry: '24h',         // 访问令牌过期时间
  refreshTokenExpiry: '7d',         // 刷新令牌过期时间
  issuer: 'marketbook',             // JWT签发者
}
```

### 安全配置 (`config.security`)

```javascript
{
  cors: {
    origin: '*',                    // CORS来源（生产环境必须设置具体域名）
    credentials: true,
  },
  rateLimit: {
    windowMs: 900000,               // 15分钟窗口
    max: 100,                       // 每窗口最多100请求
  },
  password: {
    minLength: 8,
    requireUppercase: false,
    // ... 其他密码策略
    lenient: true,                  // 开发环境放宽限制
  },
}
```

### 日志配置 (`config.logging`)

```javascript
{
  level: 'debug',                   // 日志级别：debug|info|warn|error
  format: 'json',                   // 日志格式：json|simple|combined
  file: {
    enabled: true,
    dirname: 'logs',
    maxSize: '10m',
    maxFiles: '7d',
  },
  console: {
    enabled: true,
    colorize: true,                 // 开发环境彩色输出
  },
}
```

### 交易模拟配置 (`config.trading`)

```javascript
{
  initialBalance: 100000,           // 初始资金
  marketDataUpdateInterval: 5000,   // 行情更新频率（毫秒）
  priceVolatility: 0.02,            // 价格波动范围（2%）
  supportedSymbols: ['AAPL', ...],  // 支持的股票代码
}
```

## 环境变量

所有配置都可通过环境变量覆盖，详见 `.env.example`。

### 关键环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `NODE_ENV` | 运行环境 | `development` |
| `PORT` | 服务器端口 | `3000` |
| `JWT_SECRET` | JWT密钥 | ⚠️ 生产环境必须修改 |
| `CORS_ORIGIN` | CORS来源 | ⚠️ 生产环境必须设置 |
| `LOG_LEVEL` | 日志级别 | `debug` |
| `TRADING_INITIAL_BALANCE` | 初始资金 | `100000` |

## 配置验证

配置系统会自动验证必需配置：

```javascript
// 自动验证（启动时执行）
config.validate();

// 手动验证
config.validate();
```

### 生产环境必需配置

- ✅ `JWT_SECRET` 必须修改（不能使用默认值）
- ✅ `CORS_ORIGIN` 必须设置具体域名（不能为 `*`）
- ✅ `SESSION_SECURE` 必须为 `true`

### 条件验证

- 邮件启用时，必须设置 `SMTP_USER` 和 `SMTP_PASS`
- Alpha Vantage 启用时，必须设置 `ALPHA_VANTAGE_KEY`

## 最佳实践

### 1. 敏感信息使用环境变量

```javascript
// ❌ 不要硬编码敏感信息
const secret = 'my-secret-key';

// ✅ 使用环境变量
const secret = config.jwt.secret;
```

### 2. 生产环境配置检查

```javascript
if (config.isProduction()) {
  if (config.jwt.secret === 'your-secret-key-change-in-production') {
    throw new Error('JWT_SECRET must be set in production');
  }
}
```

### 3. 使用配置默认值

```javascript
// 提供合理的默认值，方便开发
const port = config.server.port || 3000;
```

### 4. 环境差异化配置

```javascript
// 开发环境放宽限制
if (config.isDevelopment()) {
  config.security.password.lenient = true;
}
```

## 常见问题

### Q: 为什么启动时报配置验证失败？

A: 检查生产环境必需配置是否设置：
- `JWT_SECRET` 必须修改
- `CORS_ORIGIN` 必须设置具体域名
- `SESSION_SECURE` 必须为 `true`

### Q: 如何覆盖默认配置？

A: 在 `.env` 文件中设置对应的环境变量：
```bash
# 覆盖端口
PORT=8080

# 覆盖日志级别
LOG_LEVEL=info
```

### Q: 测试环境如何隔离配置？

A: 使用 `.env.test` 文件：
```bash
# 运行测试时自动加载
npm test
```

### Q: 如何动态修改配置？

A: 配置在启动时加载，动态修改需要重启服务。如需运行时修改，考虑使用配置中心（如 etcd、Consul）。
